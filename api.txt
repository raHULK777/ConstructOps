
📑 API Route Matrix & Contract Specifications

Project Name: ConstructOps Engine
Version: 1.0.0 (MVP Implementation Specification)
Author/Context Builder: Lead Architect

1. Global API Rules for the AI Agent

The AI agent must build all endpoints following these architectural interface rules:
1. Base Path Standard: All service routes must mount under the /api/v1 entry path prefix.
2. Standard Payload Wrapper: Every API response must return a consistent JSON structure containing a success boolean wrapper flag.
3. MIME Processing Matrix: All incoming request payloads must be parsed as application/json. Multi-part form streaming is rejected in this phase.

❌ Global Standard Error Matrix

The AI agent must intercept all execution thread failure vectors and map them to this predictable JSON output structure:

Scenario	HTTP Status Code	Response Payload Structure
Invalid Auth Token Scope	401 Unauthorized	{"success": false, "error": "Access token missing or expired."}
Cross-Tenant Injection Mismatch	403 Forbidden	{"success": false, "error": "Access token scope does not match current tenant domain context."}
Resource Missing / Wrong ID	404 Not Found	{"success": false, "error": "Requested record resource not found."}
Zod Input Struct Failures	400 Bad Request	{"success": false, "error": "Validation failed: squareFootage must be a positive integer."}
