
📐 ConstructOps Visual Specifications & UI Engine Guide

This guide establishes the visual boundaries, component tokens, and structural rules for the ConstructOps dynamic skinning engine. It maps abstract tenant branding variables into a predictable, high-contrast, responsive layout tailored for field superintendents on iPads and executives in modern offices.

🎨 Core Color Tokens & Contrast Map

To prevent contractors from picking colors that break user interfaces (e.g., placing white text on a neon yellow button), the system uses a computed adaptive utility layer.
The system maps client input strings directly to four foundational semantic CSS properties:

CSS Variable	Tailwind Utility	System Definition & Contrast Constraint
--primary-color	bg-brandPrimary	Master Branding Identity: Used for navigation bars, primary active states, and structural identity. Minimum 4.5:1 contrast against text.
--secondary-color	bg-brandSecondary	Action & Highlights: Used for primary CTAs (e.g., "Approve Change Order"), checkmarks, and progress indicators.
--brand-bg	bg-brandBackground	Canvas Layer: Defaults to a muted grey (#F8FAFC). Provides a clean surface that separates layout components.
--brand-surface	bg-brandSurface	Card / Data Wrapper: Isolated absolute white (#FFFFFF). Houses tables, forms, and project feeds.

📏 Typography, Radius, & Layout Grids

The application architecture controls shape language and typography sizing using data tokens retrieved at runtime, eliminating the need to compile separate styles for different clients.
• Border Radius Mapping: var(--brand-radius) controls element roundedness. It shifts automatically based on the contractor's chosen aesthetic:
	• Sharp / Industrial (0px): For heavy commercial/steel subcontractors.
	• Standard Modern (6px - 8px): For professional residential contractors.
	• Soft / Consumer (12px): For high-end architectural designers.
• Typography Controls: var(--brand-font) dynamically updates the layout using optimized fallback stacks:
	• sans Layout Stack: var(--brand-font), system-ui, -apple-system, sans-serif.

🏗️ Component Rules & Visual Standards


1. Primary Call-to-Action (CTA) Button

The central interactive component uses an automatic text color calculation system based on contrast logic to handle varying secondary accent colors safely.
tsx
// components/ui/Button.tsx
import React from 'react';

export function BrandButton({ children, onClick }: { children: React.ReactNode, onClick: () => void }) {
  return (
    <button
      onClick={onClick}
      style={{
        borderRadius: 'var(--brand-radius)',
      }}
      className="bg-brandSecondary text-slate-950 px-5 py-2.5 font-semibold text-sm hover:opacity-90 active:scale-[0.98] transition-all shadow-sm focus:outline-none focus:ring-2 focus:ring-brandPrimary focus:ring-offset-2"
    >
      {children}
    </button>
  );
}
Use code with caution.

2. Progress Tracker Component

Progress bars scale horizontally across the interface, using a subtle overlay of the brand's secondary color on top of a muted surface background.
tsx
// components/ui/ProgressBar.tsx
export function ProgressBar({ percentage }: { percentage: number }) {
  return (
    <div className="w-full bg-slate-100 h-2.5 rounded-full overflow-hidden">
      <div 
        className="bg-brandSecondary h-full rounded-full transition-all duration-500 ease-out"
        style={{ width: `${percentage}%` }}
      />
    </div>
  );
}
Use code with caution.

3. Client Workspace Data Cards

Data cards separate transactional records (such as change orders or material sheets) into highly readable blocks that match the tenant's chosen rounding profile.
tsx
// components/ui/DataCard.tsx
export function DataCard({ title, children }: { title: string, children: React.ReactNode }) {
  return (
    <div 
      style={{ borderRadius: 'var(--brand-radius)' }}
      className="bg-brandSurface border border-slate-200/80 p-6 shadow-sm hover:shadow-md transition-shadow duration-200"
    >
      <h3 className="text-slate-900 font-semibold text-lg tracking-tight mb-4 border-b border-slate-100 pb-2">
        {title}
      </h3>
      <div className="text-slate-600 text-sm leading-relaxed">
        {children}
      </div>
    </div>
  );
}
Use code with caution.

🔍 Operational Quality Controls

1. Strict Image Scaling: Contractor logos inside navigation templates are restricted to a max height of 32px (h-8) with object-contain settings. This prevents oversized images from breaking layout heights.
2. Focus Ring Fallbacks: Focus outlines must always point to focus:ring-brandPrimary. This ensures accessible keyboard navigation matches the tenant's brand color across all input components.
