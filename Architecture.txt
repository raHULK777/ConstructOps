2. Global State & Context Strategy

The platform behaves as a completely stateless API service cluster. The execution lifespan of every incoming request relies entirely on a sequential, lifecycle hydration process:
1. DNS Context Extraction: The platform pulls the current host string via req.headers.host.
2. Fast-Cache Memory Hydration: The backend checks Redis for the configuration details matching that host.
3. Database Fallback: If the cache misses, the backend reads the tenants table from PostgreSQL and saves the result to Redis.
4. Context Injection: The matching configuration object is attached to req.tenant for all remaining routing loops.

3. Asynchronous Error Handling Pipeline

The AI agent must never use standard try-catch blocks inside individual routing controllers. To prevent memory leaks and unhandled promise rejections, all asynchronous controllers must be wrapped in a global exception execution utility.

The Required Controller Wrapper

typescript
// utils/asyncHandler.ts
import { Request, Response, NextFunction } from 'express';

export const asyncHandler = (fn: Function) => (req: Request, res: Response, next: NextFunction) => {
    Promise.resolve(fn(req, res, next)).catch(next);
};
Use code with caution.

The Global Express Exception Handler

typescript
// middleware/errorHandler.ts
import { Request, Response, NextFunction } from 'express';

export function globalErrorHandler(err: any, req: Request, res: Response, next: NextFunction) {
    console.error(`[SYSTEM CRITICAL ERROR]: ${err.message}`, err.stack);
    
    const statusCode = err.statusCode || 500;
    return res.status(statusCode).json({
        success: false,
        error: err.message || 'Internal Server Infrastructure Exception Triggered.',
        timestamp: new Date().toISOString()
    });
}
Use code with caution.
